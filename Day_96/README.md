# 🚀 Custom API Web Application (Day 96)

An interactive web application built with **Python** and **Streamlit** that consumes a custom/external API to fetch and display dynamic data in real-time.

## 🌐 Live Demo

You can try out the live application directly in your browser:

👉 **[Launch Streamlit App](https://udemy-100-days-of-code-jzker4if3s4ervwm3qqqxa.streamlit.app/)**

---

## ✨ Features

- **Interactive UI:** Clean and responsive user interface powered by Streamlit.
- **API Integration:** Real-time data fetching using the `requests` library.
- **Dynamic Content:** Seamless handling and visualization of API responses.

---

## 🛠️ Tech Stack

- **Language:** Python 3.11
- **Framework:** Streamlit
- **HTTP Client:** Requests
- **Hosting:** Streamlit Community Cloud
