# 🛒 E-Commerce Web Application (Streamlit + Stripe)

A full-stack e-commerce web application built using Python, Streamlit, SQLAlchemy, and Stripe API integration. Users can register/login, browse products, manage their shopping cart, and complete test payments via Stripe Checkout.

---

## 🌐 Live Demo

Check out the live running application here:  
👉 **[Launch E-Commerce App](https://bdgnh6zhhk4vyqzugwyqtw.streamlit.app/)**

---

## ✨ Features

* **User Authentication:** Secure registration and login using hashed passwords with `bcrypt`.
* **Dynamic Catalog:** Product listing backed by an SQLite database via `SQLAlchemy`.
* **Shopping Cart:** Interactive session-based state management using `st.session_state`.
* **Stripe Checkout Integration:** Seamless test payment flows powered by the `stripe` Python SDK.
* **Responsive UI:** Streamlit-native grid layout and sidebar configuration.

---

## 🛠️ Tech Stack

* **Frontend & Framework:** [Streamlit](https://streamlit.io/)
* **Database & ORM:** SQLite, [SQLAlchemy](https://www.sqlalchemy.org/)
* **Payment Gateway:** [Stripe API](https://stripe.com/)
* **Security & Auth:** `bcrypt`
* **Language:** Python 3.x
